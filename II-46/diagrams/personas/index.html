Caso de ejemplo: CRUD de Persona VB.NET + ADO.NET

Este ejercicio muestra una arquitectura simple en capas (UI → Service → Data → DB) y su diagrama de clases. Incluye los diagramas exportados y los archivos .mmd para descarga.

Pasos del ejercicio

  1. Crear la entidad Persona (propiedades básicas).
  2. Crear DbHelper para manejar conexión y ejecución de comandos (con parámetros).
  3. Crear PersonaDB con CRUD (GetAll, GetById, Insert, Update, Delete).
  4. Crear PersonaService para reglas/validaciones (no SQL, solo lógica).
  5. En UI (Form / WebForm): cargar GridView, seleccionar registro, cargar en formulario y guardar.
  6. Usar SwalUtils únicamente en la capa UI para mostrar errores/confirmaciones.
  7. Probar: Insert → Listar → Editar → Eliminar, verificando que el ID se maneje con DataKeys / estado de edición.
